Field Teks

Field Teks = potongan tulisan yang dicetak di atas background (mis. nama peserta, nomor sertifikat, tanggal). Tambah satu field untuk tiap tulisan.

❔ Penjelasan tiap kolom (buka kalau bingung)
Key
Kode kolom data. Harus sama persis dengan judul kolom di file Excel/CSV pada langkah Generate (contoh: nama, nomor). Tulis tanpa spasi.
Label
Nama tampilan yang bebas Anda tentukan, hanya untuk memudahkan Anda sendiri. Tidak ikut tercetak di sertifikat.
Halaman
Centang di halaman mana tulisan ini dicetak. 1 = background depan, 2 = background belakang.
Perataan
Titik acuan posisi X. Kiri = X di tepi kiri tulisan. Tengah = X di titik tengah tulisan (paling pas untuk nama peserta agar selalu center). Kanan = X di tepi kanan tulisan.
Posisi X (pt)
Jarak mendatar dari tepi kiri kertas. Satuannya sama seperti angka posisi di Canva. Kosongkan = otomatis ke tengah kanvas (kalau Perataan = Tengah).
Posisi Y (pt)
Jarak dari tepi atas kertas ke baris tulisan. Makin besar angkanya, makin ke bawah.
Font
Jenis huruf. Pilih dari font yang sudah di-upload. (fallback) = huruf bawaan sistem.
Upload font baru
Menambah file font .ttf / .otf. Setelah di-upload, font langsung dipakai untuk field ini dan bisa dipilih field lain.
Ukuran Font (pt)
Besar huruf. Pakai angka yang sama dengan ukuran font di Canva.
Ukuran Min (pt)
Batas paling kecil huruf saat menyusut otomatis. Bekerja bersama "Lebar Maks". Boleh dikosongkan.
Lebar Maks (pt)
Lebar area tulisan. Kalau tulisan lebih panjang dari ini, ukuran huruf otomatis dikecilkan bertahap sampai "Ukuran Min". Berguna untuk nama yang panjang. Kosongkan = huruf tidak pernah dikecilkan.
Warna
Warna huruf. Klik kotak untuk memilih.
Contoh Nilai
Teks contoh untuk Pratinjau saja (mis. "Budi Santoso"). Saat Generate, otomatis diganti data asli dari Excel/CSV.
